# Portfólio — GitHub Pages

Esta pasta contém o site estático de currículo de Michael Salvador.

## Publicação

1. Crie no GitHub o repositório público `DevStarrk1137.github.io`.
2. Copie o conteúdo desta pasta para a raiz do repositório.
3. Faça commit e push para a branch `main`.
4. No repositório, acesse **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e a pasta `/(root)`.

Após a publicação, o endereço será:

<https://devstarrk1137.github.io/>

O GitHub informa que a primeira publicação pode levar alguns minutos. Antes de tornar o repositório público, confira se o telefone e o e-mail devem permanecer visíveis no site.
