# Portfólio — Michael Salvador

Site estático com apresentação profissional, projetos, competências, certificações e currículo em PDF.

## Site publicado

<https://devstarrk1137.github.io/>

## Estrutura

- `index.html`: conteúdo e estrutura da página;
- `styles.css`: identidade visual e layout responsivo;
- `curriculo.pdf`: currículo disponível para download;
- `.nojekyll`: publicação direta dos arquivos estáticos pelo GitHub Pages.

O GitHub Pages publica automaticamente a branch `main` com HTTPS. Telefone e e-mail presentes no site são informações públicas.
