# Portfólio v2 — Michael Salvador

Site estático bilíngue com apresentação profissional, projetos detalhados,
decisões técnicas, diagramas de arquitetura, competências, certificações e
currículos em PDF.

## Site publicado

<https://devstarrk1137.github.io/>

## Estrutura

- `index.html`: versão em português;
- `en.html`: versão em inglês;
- `styles.css`: identidade visual e layout responsivo;
- `assets/`: diagramas de arquitetura em português e inglês;
- `resumes/`: currículos em português e inglês;
- `curriculo.pdf`: cópia do currículo em português para compatibilidade com links antigos;
- `.nojekyll`: publicação direta dos arquivos estáticos pelo GitHub Pages.

O GitHub Pages publica automaticamente a branch `main` com HTTPS. Telefone e e-mail presentes no site são informações públicas.
