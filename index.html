Projeto 01

Wallet API

Java 21 · Spring Boot · PostgreSQL · Docker

Challenge concluído · set/2026

API REST de transferências entre carteiras, construída para manter as invariantes monetárias mesmo sob concorrência e falhas de serviços externos.

Decisões técnicas

  • Transação única para débito, crédito e criação da notificação pendente.
  • Locks pessimistas em ordem determinística para impedir gasto duplo e reduzir risco de deadlock.
  • Retentativas de notificação persistentes com FOR UPDATE SKIP LOCKED.

Evidência

  • 49 testes: 28 de integração, 14 de clientes HTTP e 7 de domínio.
  • PostgreSQL real em Testcontainers.
  • Cenários de rollback, concorrência, timeout e indisponibilidade.

Projeto 02

Ayvu

Python 3.11+ · SQLite · pytest · EPUB

CLI funcional · evolução ativa · set/2026

Ferramenta local-first para traduzir e revisar EPUBs sem alterar o original, preservando a estrutura do arquivo e enviando ao tradutor apenas conteúdo visível.

Entregue hoje

  • Preview, batch, seleção de capítulos, cache SQLite e modo cache-only.
  • Checkpoints, retomada, glossários, memória por similaridade e revisão CSV.
  • Controles de concorrência, rate limit, retries e validação do EPUB produzido.

Em evolução

  • Projetos e jobs persistentes com artefatos versionados e proveniência.
  • Núcleo modular compartilhável com uma futura interface desktop.
  • Políticas explícitas de privacidade, rede e operação estritamente offline.

Evidência: 330 testes automatizados em 21 arquivos; arquitetura e roadmap públicos não são apresentados como funcionalidades prontas.

Projeto 03

Lume

Java · Interpretadores · Tipagem estática

Funcional e documentado · set/2026

Linguagem de programação com inferência estática, traits e módulos verificados antes da execução, construída sobre um interpretador tree-walk.

Pipeline

Projeto 04

Tailwarden

Go · AWS SDK v2 · Lambda · SAM

Challenge concluído · set/2026

API que inventaria funções Lambda em todas as regiões habilitadas de uma conta AWS sem transformar a latência de rede em processamento sequencial ilimitado.
